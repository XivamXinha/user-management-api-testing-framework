# User Management API Testing Framework

This project demonstrates REST API testing using Postman and Newman. The framework covers CRUD operations (Create, Read, Update, Delete), response validation, assertions, environment variables, and automated collection execution.

## Features

- Create User API Testing
- Get User API Testing
- Update User API Testing
- Delete User API Testing
- Response Validation
- Status Code Verification
- Environment Variables
- Newman Execution

## Tools Used

- Postman
- Newman
- ReqRes API
- JSON

## Test Scenarios

- Validate Create User API (POST)
- Validate Get User API (GET)
- Validate Update User API (PUT)
- Validate Delete User API (DELETE)
- Verify Response Status Codes
- Verify Response Body Data
- Store and Reuse Variables

## Expected Outcomes

- Automated API Validation
- Reduced Manual Testing Effort
- Reusable API Test Collection
